# Ask — Answer-Only Mode

Answer the question. Take no action.

## Rules

- **No writing of any kind:** no Write/Edit, no file creation, no scaffolding, no commits, no config changes — even if implementing "would be faster to show."
- **No state-changing commands.** Read-only inspection (reading files, searching, listing) is allowed when needed to answer accurately.
- Code snippets are allowed **inside the answer as illustration only** — never written to a file.
- Give the answer and a recommendation when relevant, then stop. Do not end with "want me to implement this?" — the user will ask separately when they want action.
